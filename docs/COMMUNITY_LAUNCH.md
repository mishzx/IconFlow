# Welcome to IconFlow / 欢迎来到 IconFlow

**Make Windows folders easier to recognize—and easier to undo.**  
**让 Windows 文件夹一眼可辨，也随时可恢复。**

<p align="center"><img src="https://raw.githubusercontent.com/mishzx/IconFlow/main/docs/media/iconflow-quick-change.gif" width="470" alt="IconFlow quick change demo"></p>

IconFlow started from a small frustration: changing a folder icon on Windows still exposes image conversion, configuration files and Explorer cache behavior. The project turns that fragmented process into a compact native WinUI 3 action while treating undo and recovery as core features.

The current public preview supports folders and `.lnk` shortcuts, a compact Explorer picker, a local icon library, seven-layer ICO generation, editing, grouped recovery history and 11 interface locales. It has no account, telemetry, upload or background network service.

- Download v0.8.2: https://github.com/mishzx/IconFlow/releases/tag/v0.8.2
- Read the project page: https://github.com/mishzx/IconFlow
- Report a bug: https://github.com/mishzx/IconFlow/issues/new/choose

I would especially value real-world feedback on Windows 10/11 behavior, 100–200% scaling, Explorer refresh reliability, accessibility and translation quality. Please remove private paths and personal files from screenshots before posting.

IconFlow 源于一个很小却长期割裂的问题：在 Windows 上更换文件夹图标，仍会让用户接触图片转换、配置文件和资源管理器缓存。这个项目希望用一个小巧的原生 WinUI 3 操作收拢整个过程，同时把撤销与恢复作为核心能力，而不是事后补丁。

当前公开预览版支持文件夹和 `.lnk` 快捷方式、资源管理器轻量选择器、本地图标库、七层 ICO 生成、图标编辑、按对象折叠的恢复历史，以及 11 种界面语言资源。软件不需要账号，不包含遥测、上传或后台联网服务。
