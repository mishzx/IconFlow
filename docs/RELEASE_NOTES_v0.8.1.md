# IconFlow 0.8.1

IconFlow 0.8.1 is the first public native preview: a compact Windows icon workflow built around reversibility, local processing and visual calm.

## Included

- Native WinUI 3 application and Fluent interface.
- Folder and shortcut icon replacement.
- Compact File Explorer picker.
- Seven-size ICO generation and a local icon library.
- Crop, padding, rounded-corner, base-shape and background-removal tools.
- Grouped history with before/after previews and undo.
- 11 interface languages.
- Nine coordinated built-in Fluent folder icons.

## Important installation note

The portable application can be extracted and run directly. The optional Windows 11 first-level context menu uses a sparse MSIX signed with a project-local development certificate, so Windows requests administrator confirmation when installing that component. The compatibility context menu does not require elevation.

## Privacy

No account, telemetry, file upload or background network connection is included. User paths and icon history stay on the device.

## Verification

The release build runs the native regression suite and validates the WinUI resources, Shell Extension, multilingual resources and built-in icon layers before packaging.
