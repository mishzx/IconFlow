# IconFlow Native

![IconFlow WinUI 3 デモ](docs/media/iconflow-demo.gif)

IconFlow は、ローカル優先で動作し、変更を元に戻せる Windows 向けアイコン管理ツールです。フォルダーやショートカットのアイコン変更、アイコンライブラリの整理、履歴の確認とロールバックを、軽量なネイティブ UI にまとめています。

IconFlow の意義は、単にアイコンを変えることではありません。フォルダーアイコンは、個人の知識ベースや研究資料、日々のワークフローを案内する最初の視覚的なナビゲーションです。アイコン、分類、コレクション、履歴をローカルで管理することで、必要な情報を見つけやすくしながら、ファイル名・パス・インポート素材を自分のデバイスの外へ出さない設計を目指します。プロジェクトは MIT ライセンスで公開しています。

> 現在のネイティブ主線バージョン: `0.8.2`。公開リポジトリには、保守対象のネイティブ版のみを収録しています。

## IconFlow の特徴

- **軽量なネイティブ UI**: .NET 8、Windows App SDK / WinUI 3 を基盤とし、Windows のネイティブコントロールと Mica を使用します。Chromium の起動は不要です。
- **ローカル優先**: インポート、プレビュー、編集、バックアップ、履歴、検索はデバイス上で処理します。既定ではネットワーク通信やファイルのアップロード、アカウント登録を必要としません。
- **復元可能**: アイコン適用前に自動バックアップを作成し、変更前後のアイコンを確認して項目ごとに取り消せます。既定のアイコンへの復元にも対応します。
- **Explorer に自然に統合**: Windows 11 の第 1 階層の右クリックメニューと、管理者権限を必要としない互換メニューを提供します。
- **実際の整理作業向け**: ライブラリのフォルダー、検索、コレクション、重複検出、最近使用した項目を備えた、継続的に使えるツールです。

## 主な機能

- 通常のフォルダーと `.lnk` ショートカットのアイコン変更。
- PNG、JPG/JPEG、WEBP、SVG、BMP、ICO の読み込みと EXE アイコンの抽出。
- 16、24、32、48、64、128、256 の 7 サイズを含む ICO の自動生成。
- アイコンライブラリの検索、コレクション、重複検出、最近使用した項目、フォルダー分類、新規作成・名前変更・ドラッグ整理。
- 文献、データ、コード、実験、写真、臨床、タスク、完了、アーカイブ向けの Fluent フォルダーアイコンパック。
- ネイティブエディター: 自由/固定比率のトリミング、拡大縮小、オフセット、透明余白、角丸、背景図形と色。
- 背景色と許容差を指定した、連結した外周背景の除去。内部の白い記号は保持します。
- 右クリックのクイックウィンドウ: マウス付近への表示、画面端の自動回避、リアルタイム検索、画像のドラッグ&ドロップと即時適用。
- アイコンの右クリック操作: 名前変更、編集、移動、コレクション追加、安全な削除。
- バージョン付き 256×256 プレビューキャッシュ。ICO 内の最大 PNG レイヤーを優先し、古いキャッシュや小さなレイヤーの拡大によるぼやけを抑えます。
- 履歴、取り消し、既定値への復元、Explorer のネイティブ更新。
- ライト、ダーク、システム連動テーマと 100%–200% DPI の自動調整。
- ネイティブ多言語リソース: 簡体字中国語、繁体字中国語、英語、スペイン語、フランス語、ドイツ語、ポルトガル語、日本語、韓国語、ロシア語、アラビア語。アラビア語では RTL レイアウトを使用します。

## プライバシーとデータ

IconFlow は「ファイルをデバイス内に留める」ことを基本に設計しています。

- 既定ではスタートアップ起動もトレイ常駐も行わず、最後のウィンドウを閉じるとプロセスを終了します。
- ファイル名、パス、デスクトップの内容、インポート画像をアップロードしません。既定ではネットワーク通信を行いません。
- 適用前にバックアップを作成し、適用済みアイコンを安定した `managed-icons` フォルダーにコピーします。そのため、元の素材やライブラリの場所を移動しても直ちにアイコンが壊れません。
- データの既定の保存先は `%LocalAppData%\IconFlow` です。個人のファイル名、パス、アイコンを含む診断アーカイブを公開 issue に添付しないでください。

## インストールと使い方

### ポータブル版を起動する

1. GitHub Releases から最新の `IconFlow-0.8.2-win-x64-portable.zip` をダウンロードします。
2. 書き込み可能な任意のフォルダーに展開します。
3. `IconFlow.exe` を実行します。

リリースは Windows x64 向けのネイティブビルドです。初回起動前に **.NET 8 Desktop Runtime** と **Windows App Runtime 2.4** がインストールされていることを確認してください。Windows 11 では第 1 階層の右クリックメニューを利用できます。

### 右クリックメニュー

- **Windows 11 第 1 階層**: リリースフォルダーの `Install-Win11Menu.ps1` を実行するか、設定から「Windows 11 新しいメニューをインストール / 修復」を選択します。UAC の確認が 1 回必要で、ローカル署名の sparse identity パッケージを登録します。
- **互換メニュー**: 設定で「Explorer 互換右クリックメニュー」を有効にします。現在のユーザーのレジストリだけを変更するため、管理者権限は不要です。Windows 11 の「その他のオプションを表示」に表示されます。
- **第 1 階層メニューの削除**: `Uninstall-Win11Menu.ps1` を実行します。メニューパッケージと対応する開発用署名証明書を削除します。

公開配布では、開発用証明書は検証・テスト専用です。正式な製品では、信頼されたコード署名証明書または Microsoft Store 配布へ置き換えてください。

## ソースからビルド

Windows、.NET 8 SDK、Windows App SDK の依存関係、PowerShell が必要です。

```powershell
dotnet build native\IconFlow.WinUI\IconFlow.WinUI.csproj -c Release
dotnet run --project native\IconFlow.Native.Tests\IconFlow.Native.Tests.csproj -c Release
powershell -ExecutionPolicy Bypass -File scripts\build-native.ps1
```

`native\\IconFlow.Core` には UI に依存しない Windows コアロジック、`native\\IconFlow.WinUI` にはネイティブ UI が含まれます。ビルドスクリプトは内蔵アイコンの生成、コア回帰テスト、WinUI 配布ファイル、Windows 11 メニュー拡張の準備を行います。


## 現在の制限

- 現在は Windows x64 を対象としています。システムデスクトップアイコン、ファイル種別アイコン、タスクバー、スタートメニュー、バッチルールはまだ実装対象外です。
- 第 1 階層の右クリックメニュー開発ビルドはローカル開発証明書で署名されるため、Windows の信頼確認が表示されます。公開前に再署名してください。
- 配布版は .NET 8 Desktop Runtime と Windows App Runtime 2.4 に依存します。環境差によりインストールやメニュー拡張の動作が変わる場合があります。
- クラッシュログを自動アップロードしません。問題報告では、ユーザー名、組織名、個人パス、非公開アイコン素材を削除してください。
